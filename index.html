＋ 添加剧目

故事 · 我们为何做、如何做成

把吴语里听得见的话——尤其是长辈与日常的声音——变成年轻人和外人也能跟读的档案。

为什么重要

吴语社区正在变薄：许多老人仍用家乡话过日子，舞台上的越剧、书场里的弹词、广播里的口音，却越来越少被下一代听懂。越语侦听想留下可对读的声音样本——不夸大抢救，只认真记录，尤其珍视长辈与女性日常说话人的声音。

问题从哪里来

方言流失之外，还有一道缝：台上的韵白、散白与街上的口语并不相同。年轻人或外人往往能“听热闹”，却读不出字句。我们从越剧切入，也把弹词文字层与广播口语放进同一张地图，让对话既听得见，也读得懂。

01

收集与整理

从本地戏曲、弹词相关文本与广播选段出发，建立清单与精选片段，而不是把整包音频丢上公网。

02

转写与翻译

为选段加上时间轴、说话人、简体 / 繁體 / English，并写清剧情简介，让不懂戏的人也能跟得上。

03

真人试听检验

请熟悉方言或戏曲的长辈与本地说话人试听、试说，对照识别结果是否“说得通、听得懂”。

04

用档案反哺识别

把校对过的语料当作训练与评测依据，让听说翻译从“普通话基线”慢慢靠近越语与吴语现场。

当前识别仍是基线演示。故事的重点是方法与动机：听见吴语、读懂对话、请真人检验，再慢慢改进——而不是假装已经完美。

项目计划

越语侦听：面向越语变体的语言识别——以越剧舞台方言（韵白 / 散白）为切入，不限于单一剧目。

Task calibration

Scope is 越语 (Yueyu) linguistic ASR — broader than 越剧 alone. Yue opera stage dialect (韵白 / 散白 / 中州韵 hybrid) is the first high-value domain; everyday Shengzhou / Shaoxing speech can be mixed in later.

Two output layers planned:

  • 汉字戏词 / 汉字转写 — most practical for school demos and archive reading
  • wugniu 嵊州拉丁化 + 声调 — high research value for Wu linguistics; smaller audience

Phase 1 targets 汉字. Phase 2 adds 嵊州拼音 layer.

Speech types

  • 散白 — closer to everyday Shengzhou speech; relatively easier to recognize
  • 韵白 — hybrid of 中州韵 + Wu tones; where generic ASR fails hardest

Resource types & pipeline

Source Examples Approach
Official recordings CCTV, Zhejiang TV, Shaoxing Xiaobaihua DVDs Extract audio + OCR subtitles → Whisper alignment → human correction
Scripts / subtitles 戏考网, troupe publications OCR + aeneas / whisper-timestamped coarse align → manual fix
Private corpus packs Local Baidu 越剧-1451首 (~1,200+ tracks) Inventory locally; publish curated clips + text only
Live / fan covers Bilibili uploads test-live split; contemporary pronunciation distribution

Model approach

Don't train from scratch — Whisper-small (244M) + LoRA r=32 is the fastest open-source path.

  • Encoder: frozen or LoRA on q,v (r=8)
  • Decoder: tokenizer + ~200 吴语特字; LoRA r=32 on q,k,v,o
  • Output: 汉字 with timestamps
  • Optional second pass: wugniu-嵊州拼音 via small LM

200–500 hours of aligned data → usable small model. 1000 hours → medium or Data2vec2 + Qwen2 0.5B.

For broader 越语 coverage beyond Yue opera, mix everyday Shengzhou/Shaoxing speech with stage data.

Phonology & 韵白

Yue opera is based on 嵊州话 (Taihu Wu, Lin-Shao sub-group), but 韵白 is a hybrid — not pure Shengzhou.

  • 吴语学堂 wugniu has Shengzhou data for 特字 ↔ pinyin mapping
  • 《嵊县志·方言编》 + 钱乃荣《吴语声调实验录》 for tonal acoustics
  • Stage "Shengzhou" ≠ everyday Shengzhou — document scope clearly in README

2. 网站介绍

越语侦听 是产品化的演示与档案网站，两大支柱同等重要：

  • 听说翻译 — 麦克风或上传音频，识别后阅读简体、繁體与英文
  • 档案 — 浏览带剧情简介与时间轴的越语 / 越剧对话选段

使用方式

  1. 打开「听说翻译」：允许麦克风（推荐 Chrome / Edge），或选择音频文件
  2. 说完稍等几秒，翻译会自动出现；也可编辑识别文本
  3. 打开「档案」：选择作品，阅读剧情简介，点击时间戳跳转播放
  4. 用右上角 简体 / 繁體 / EN 切换整个网站界面语言

使用条件

  • 用于教育、研究与个人学习
  • 建议桌面版 Chrome / Edge 与稳定网络（首次 Whisper 上传可能下载小模型）
  • 识别为基线演示；越语 / 舞台方言准确度会随语料积累提升
  • 大型私有音源包留在开发者本地；网站仅展示精选片段与文本
  • 请勿用本站转售或整包传播你无权分发的录音

Yueyu Detecting is a product-style archive and demo tool with two equal pillars:

  • Speak — mic or upload audio; then read Simplified Chinese, Traditional Chinese, and English
  • Archive — timed Yueyu / Yue opera clips with plot intros and multilingual transcripts

How to use

  1. Open Speak: allow the microphone (Chrome/Edge), or choose an audio file
  2. Wait a few seconds after speech — translations appear; you can edit the recognized text
  3. Open Archive: pick a piece, read the story intro, click any timestamp to jump and play
  4. Use the top-right 简体 / 繁體 / EN switcher to change the whole site language

Conditions of use

  • For education, research, and personal learning
  • Best on desktop Chrome or Edge with a stable network
  • Recognition is a baseline demo; dialect accuracy improves as the corpus grows
  • Large private source packs stay local; the site shows curated clips and text only
  • Do not redistribute purchased recordings or claim rights you do not hold

3. 隐私

我们希望演示轻量，并尊重用户隐私。

  • 麦克风：仅在你点击开始听写时于浏览器内使用；本站不自建服务器保存你的实时录音。
  • 上传文件：尽可能在浏览器内做设备端识别。请勿上传无权处理或含敏感信息的录音。
  • 翻译：识别文本可能发送至第三方翻译接口以生成繁體 / English。请勿在识别框粘贴私密个人信息。
  • 无账号系统：无需登录，也不会有意建立用户画像。
  • 本地访问：在自己电脑打开（127.0.0.1）时，除字体、模型/CDN 与你触发的翻译请求外，流量主要留在本机。

We aim to keep the demo lightweight and respectful of privacy.

  • Microphone: used in your browser only when you start listening. We do not run a custom server that stores live mic audio.
  • Uploads: processed in-browser for on-device recognition when possible. Do not upload recordings you are not allowed to process.
  • Translation: recognized text may be sent to a third-party API for Traditional Chinese / English. Avoid pasting private personal data.
  • No accounts: no login and no intentional user profiling.
  • Local hosting: on your machine (127.0.0.1), traffic stays local except fonts, model/CDN assets, and translation requests you trigger.
