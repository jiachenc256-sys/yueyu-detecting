## 结论（选这条）

**以「承认当前上限 + 双指标诚实展示」为主**，不靠剔掉难句把 mean CER 刷到 0.5。

| 选项 | 判断 |
|------|------|
| ① 继续猛训 | 可做轻量续训，但 ROI 低：v12→v13 只 −0.02；文案听校已确认金标正确，模型仍 CER≈1 的句不是标错 |
| ② 把 CER≈1 的 test 句移出硬指标 | **不当主叙事**——会得到好看数字，但不诚实；最多作「易句子集」附录 |
| ③ 承认上限 + 双指标 + 定性样例 | **首选**：作业/面试讲清「相对同尺寸基线大降 + 未见全剧仍难」 |
