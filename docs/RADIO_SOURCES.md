# 电台 / 广播口语素材：去哪里找

目标：为 Archive「广播 · 日常吴语」收集短片段（建议先 1–3 分钟），再人工转写。  
注意：绍兴一带**很少有全天方言频道**；多数是普通话节目里穿插绍兴话 / 嵊州话，或戏曲、教学栏目。

---

| 平台 | 怎么搜 | 适合做什么 |
| :--- | :--- | :--- |
| **蜻蜓 FM** | App / 网页搜台名或节目名 | 回听、节目单、下载片段 |
| **喜马拉雅** | 搜「绍兴话」「嵊州」「越剧」 | 教学、故事、戏曲切片 |

## 二、本地频率（先盯这些台）

### 1. 柯桥经典汽车广播 **FM106.8**（原 FM106）

- 平台入口（蜻蜓）：[柯桥调频 / FM106.8 相关频道](https://m.qingting.fm/channels/2422/)
- **重点节目（方言向）**  
  - 《**学好绍兴话，走遍绍兴都不怕**》— 小娜、丰哥等主持，明确做绍兴话  
  - 在蜻蜓 / 喜马拉雅搜完整节目名即可找往期  
- 其他栏目多为普通话 + 本地话题，偶有方言互动，可当备选

### 2. 绍兴音乐广播 **FM103.5**

- 蜻蜓：[FM103.5 绍兴音乐广播](https://m.qingting.fm/channels/5054/)  
- 以音乐、早晚高峰为主，**方言密度通常低于 FM106.8**，适合顺带听、不优先

### 3. 绍兴新闻广播 **FM93.6 / AM738**

- 时政新闻为主，普通话多  
- 偶有本地连线；不适合当方言主来源

### 4. 嵊州电台 **FM100.3**

- 本地称呼：嵊州交通娱乐广播  
- 微信可搜：**嵊广1003**  
- App：**嵊州手机台**（融媒体客户端，含广播直播）  
- 品牌栏目举例：《城市早班车》《嵊州晚高峰》《上午好我的亲》等  
- **不一定全程方言**，但嵊州本地口播更接近项目目标口音，值得抽听

## 五、实用采集流程（建议）

1. 打开蜻蜓 → 搜《学好绍兴话，走遍绍兴都不怕》→ 选一集清晰的短段。  
2. 先听 30 秒：确认是绍兴话互动，不是纯普通话讲解。  
3. 导出 / 录屏转音频，剪 **1–3 分钟**，静音处可切开。  
4. 记下：台名、节目名、日期、主播、是否获授权（公开回听 ≠ 可商用；教育展示需谨慎，优先短引用 + 注明来源）。  
5. 人工写简体时间轴，再补繁体 / 英文。

---

## 六、版权与伦理（短记）

- 公开站点不要整集上传商业广播。  
- 试点用**短片段 + 来源说明**；若要长期挂站，联系电台或使用自采同意录音。  
- 长辈面对面口语（有同意书）往往比电台更好控版权，也可与广播并行。

---

## 七、第一次试点推荐（最少步骤）

1. 蜻蜓搜：**学好绍兴话，走遍绍兴都不怕**  
2. 再备选：微信 **嵊广1003** / App **嵊州手机台** 听早高峰口播  
3. 各剪 1 段 1–2 分钟，做人转写，放进 Archive `broadcast`
